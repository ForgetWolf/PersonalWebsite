# Page routes

Desktop entry: `/desktop`. Legacy `/random` redirects to `/desktop`.
Mobile entry: `/mobile`. Internal build sources still live in `random/`.

Local pages: `/about`, `/friends`, `/contact` (static HTML, no CGI).
Their content comes from `source/about.md`, `source/friends.md` and
`source/contact.md`. Front matter `desc` supplies the summary and `date`
supplies the last edited date. The Markdown body supplies page content.
`{{ ... }}` wrappers in metadata are removed for display.

After editing these files, run `python pages/generate.py` from the project
directory, then refresh the page. Build dependency: `Markdown==3.11.2`
(install with `python -m pip install --target .tools Markdown==3.11.2`).
The main page is not generated by this script.
Both menus use the requested production URLs under forgetwolf.net, with Blog
under blog.forgetwolf.net. Local preview does not deploy those domains or
change DNS; open the local page routes directly to inspect the pages.
