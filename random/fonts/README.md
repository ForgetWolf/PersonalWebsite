# Landing typeface

## Terminal output

WebPlus IBM VGA 8x16, from VileR's Ultimate Oldschool PC Font Pack v2.2.
Source: https://int10h.org/oldschool-pc-fonts/
Archive: https://int10h.org/oldschool-pc-fonts/download/oldschool_pc_font_pack_v2.2_web.zip
License: CC BY-SA 4.0; see `VGA-LICENSE.txt` and `VGA-README.txt`.
The output's glyphs are converted into SVG paths. They are a redistributable
VGA revival, not a copy of the Windows Terminal font files. SVG outline
conversions of this font retain the same CC BY-SA 4.0 attribution/license.

## Heading and tape

Alte DIN 1451 Mittelschrift (Regular), by Peter Wiegel.
Downloaded from the author's distribution:

https://www.peter-wiegel.de/alteDin1451.html
https://www.peter-wiegel.de/Fonts/Din1451altTT.zip

Copyright (c) 2017, Peter Wiegel. Reserved Font Name: Alte DIN 1451.
Licensed under SIL Open Font License 1.1; see `Open Font License.txt`.
The original archive and unmodified Regular TTF are retained here.

The generator uses fontTools (installed in the project's `.tools`) to convert
only landing text and numbers into SVG paths. It includes digits 0–9. Visitors
do not download a font or need a local installation. Greeting lettering is not
changed. Cell groups keep stable IDs and `data-text` values for future work.
